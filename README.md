# 顺丰同城 · 系列海报《同城，即同时。》

广告设计课程作业 · 平面设计 · 三联叙事海报（电子展示）

> **同城，即同时。**
> 一念起，一刻至 —— 顺丰同城

## 创意一句话

整张海报是一只钟。女主角的上半身是**分针**，腿是**时针**。
她从躺着想吃蛋糕（14:45），到半躺下单（14:50），到坐起来举着蛋糕（15:00）——
她起身的这一刻钟里，外圈的骑手也恰好从 9 点的蛋糕店骑到 12 点的家门口。

## 进度

| 阶段 | 内容 | 状态 |
|---|---|---|
| 0 方案定稿 | 创意、故事线、slogan | ✅ 完成 |
| 2 构图线框 | 指针角度、长短比例、版式 | ✅ 完成 → [`wireframes/`](wireframes/) |
| 1 视觉开发 | 风格定调 → 道具设定 | ✅ 完成（风格 A） |
| 3 正式插画 | 三张姿势图生成 + 合成 | ✅ 合成 v1 完成 → [`output/`](output/)（待审查） |
| 4 排版与文案 | slogan、时间戳、logo | ⏳ |
| 5 输出 | 3 × 2400×3200 PNG + 16:9 三联展示 + 设计说明 | ⏳ |

## 工作流

- **AI 生图（ChatGPT）**：人物与道具插画，提示词见 [`prompts/`](prompts/)
- **代码（SVG + Playwright）**：钟面、外圈、构图、合成、排版、导出，见 [`tools/`](tools/)
- 每个阶段结束由团队审查确认后再进入下一阶段

## 目录

```
docs/        创意方案、审美规划
prompts/     各阶段生图提示词与审查记录
assets/      原始草图、生成素材（按阶段/版本归档）
wireframes/  构图线框（SVG + PNG）
tools/       线框/合成脚本
```

重新生成线框：`node tools/wireframe/gen.js`（需要 Playwright）

重新合成海报：`pip install scipy pillow numpy && python3 tools/compose/cutout.py && node tools/compose/compose.js`
