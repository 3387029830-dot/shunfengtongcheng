# 审美规划 v2 —— 从"温馨"升级到"高级商业"

v1 的方向是"温软、毛绒、治愈"，生成结果证明它会滑向小红书治愈插画：可爱、满、暖，但不像大品牌广告。
v2 保留温度，但把**设计感放在插画前面**。

## 原则

1. **克制**：大面积留白，元素少而准。一张图只说一件事。
2. **图形化**：钟面的几何结构是主角，人物是嵌在结构里的图形，而不是一幅场景画。
3. **对比**：干净的暖白底 + 深墨棕的结构线与文字 + 唯一一抹红。拒绝通篇米黄滤镜。
4. **成熟**：人物比例约 7 头身，五官精简，情绪内敛（微笑而不是吐舌星星眼）。
5. **质感点到为止**：只保留细微的纸张/印刷颗粒；毛绒感只留给沙发和抱枕。

## 色彩

| 角色 | 色值 | 说明 |
|---|---|---|
| 底色 · 暖白 | `#F5F1EA` | 比 v1 更干净、更亮 |
| 表盘 · 燕麦 | `#E3D7C6` | 结构面 |
| 结构/文字 · 墨棕 | `#2B2420` | 刻度、时针（裤子）、slogan，提供对比 |
| 强调 · 朱红 | `#C93A3A` | 只给卫衣（分针）、草莓、骑手路径 |
| 品牌色 | 官方 VI | 仅包装盒、logo |

## 字体

- 主 slogan：思源宋体 Bold，字距拉开
- 副文案/信息：思源黑体 Light
- 时间戳：细体数字，左上角
- "叮咚~"：可选手写，或同样用思源黑体保持克制

## 版式

3:4 竖版，2400×3200 px，RGB。表盘占宽约 70%，三张模板统一：时间戳左上、logo 右下、slogan 仅画3 表盘下方。
