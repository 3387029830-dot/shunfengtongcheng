# 顺丰同城品牌元素

来源：团队提供的官方 logo 与 4 张官方七夕广告；公开报道。

| 元素 | 规范 / 用法 |
|---|---|
| Logo | 黑色六边形"C" + 红色勾形色带（`assets/brand/logo-mark.png`，白色反白版 `logo-mark-white.png`） |
| 品牌红 | `#D7000F`（从官方 logo 取色） |
| 品牌黑 | `#1C1A19` |
| 专属配送箱 | 黑色立方体，正面 logo + "顺丰同城" + "专业同城急送"，右侧斜向红色色带（见官方广告"即刻奔赴专属心动"） |
| 品牌理念 | "专业，让配送更有温度"（2019 品牌发布） |
| 品牌定位 | "又快又稳"（2021 品牌升级） |

## 在海报中的落点

1. **表心 = logo**：她胯部的指针轴心用 logo 标记，三张都在视觉中心
2. **品牌签名**：右下角 logo + 顺丰同城 + "专业同城急送 · 又快又稳"
3. **专属配送箱**：画3 沙发前，矢量绘制，参照官方样式
4. **App 推送卡片**：画2，"顺丰同城｜骑手已取货，正在赶来"
5. **品牌红只给配送相关元素**：骑手路线、叮咚、色带
