# 参考案例与改版依据（v6）

## 调研结论

| 参考 | 学到什么 |
|---|---|
| 顺丰同城官方广告（团队提供的 4 张七夕海报；数英收录的节日营销、母亲节系列） | 情感金句 + 骑手 / 配送箱等品牌资产；大面积饱和色底；品牌元素直接 |
| 高端腕表平面广告（Rolex 60–70 年代黑底版式、Chanel 1988 等） | 深色底、表盘是唯一主角、元素极少、文字极少——我们的创意本身就是一只钟，最该借这套语言 |
| 戛纳 / D&AD 获奖平面（FedEx "Neighbours" 等） | 一个视觉想法、一眼看懂，其余全部删掉 |

## v5 的问题 → v6 的改法

1. **核心创意太小** → 表盘放大到画面宽度的 87%，人物跟着放大 13%。
2. **元素太多，像信息图** → 删掉蛋糕店、家、街道、车道线；城市道路简化为表盘内一圈细虚线，骑手骑在上面。
3. **全米色、无对比** → 品牌黑底 + 奶白表盘 + 品牌红点缀，三色系统。
4. **文字层级平均** → 只留三样：左上品牌、底部大标题、右下时间。
